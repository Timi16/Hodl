# HodL web app

Next.js 16 (App Router, Cache Components) + Tailwind 4 + motion. It talks
straight to Soroban RPC and Horizon from the browser; wallets sign through
Stellar Wallets Kit (Freighter, xBull, Lobstr, Albedo, Hana). No keys, no database.

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm lint && pnpm build
```

Works with no `.env`: `lib/config.ts` defaults to the live Testnet contract.
Override with the `NEXT_PUBLIC_*` values in `.env.example` (`scripts/deploy.sh`
writes the current ones to `deployments/testnet.env`).

## Routes

| Route | What it is |
|---|---|
| `/` | Landing |
| `/dashboard` | Overview: locked totals, what's waiting on you, all escrows |
| `/escrow/new` | Create & lock (or save to lock later) |
| `/escrow/[id]` | One escrow: status, parties, actions for your role, receipts. Shareable, with an OG card |
| `/setup` | Wallet readiness: Testnet, Friendbot XLM, USDC trustline, faucet |
| `/activity` | Every transaction on your escrows |
| `/how-it-works` | For reviewers: state machine, functions, live contract, API |

## API (read-only, keyless, CORS-open, cached ~10 s)

| Route | Returns |
|---|---|
| `GET /api/escrow/:id` | `{ escrow, phase }` |
| `GET /api/escrow/:id/events` | `{ events, truncated }`: receipts with tx hashes |
| `GET /api/escrows?ids=1,2` | `{ escrows }` (≤ 100 ids, unknown skipped) |
| `GET /api/users/:address/escrows` | `{ paying, receiving }`, plus `escrows` with `?expand=1`, `activity` with `?activity=1` |
| `GET /api/stats` | Contract id, escrow count, version, upgrade lock, admin |
| `GET /api/health` | Soroban RPC and Horizon status (not cached) |
| `POST /api/friendbot` `{ address }` | Funds a Testnet account with XLM |

The app does not depend on these: pages read the chain directly so they are always live.

## Layout

- `lib/hodl/`: reads, events, phase model (what users see), error messages, server-cached reads
- `lib/stellar/`: RPC client, the write pipeline (`tx.ts`: simulate → sign → submit → confirm), Horizon
- `components/`: `ui/` (design system + motion), `escrow/`, `tx/` (transaction toast), `wallet/`, `layout/`
- `contract/`: TypeScript bindings generated by `scripts/bindings.sh`, for integrators. The app does not import them.

Motion is functional and respects `prefers-reduced-motion`: the padlock snaps shut when
funds lock, amounts spring to new values, receipts slide in, and the ambient rings and
glows are CSS.
